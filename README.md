# SidelineReel: Roster-Tagging Accuracy

Roadmap call, spec and clickable prototype for SidelineReel (Ajaia). The P1 feature stops the wrong kid's highlight from landing in a child's reel when jersey numbers look alike (4/14, 1/11, swapped digits).

**Live prototype:** https://6ae76296b4412e9346da4632--sideline-reel-prototype.netlify.app/
